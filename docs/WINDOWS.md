# Readerka для Windows 10/11 x64

Настольная версия основана на модели Android 0.9, которая продолжает интерфейс 0.7. Изменения 0.8 не используются. Android и ПК совместно используют модели записей, форматированный текст, ссылки, папки, версии и формат резервной копии.

## Скачать и запустить

[Windows ZIP](https://github.com/rampe22mesler-dot/readerka/blob/codex/readerka-desktop-windows/downloads/readerka-0.9.1-desktop-windows-x64.zip) · [Android 0.9.1 Preview](https://github.com/rampe22mesler-dot/readerka/blob/codex/readerka-desktop-windows/downloads/readerka-0.9.1-preview.apk)

Репозиторий закрытый: войдите в GitHub под аккаунтом с доступом, откройте страницу файла и нажмите **Download raw file / View raw**. Прямая ссылка raw.githubusercontent.com может вернуть 404 даже при входе в браузере.

1. Полностью распакуйте Windows ZIP в обычную папку.
2. Откройте **Readerka.cmd** в папке Readerka. Java уже включена; установки и подключения к сети для работы с библиотекой не требуется.
3. При ошибке запуска откройте **Diagnostics.cmd**. Ошибка запуска также сохраняется в `%LOCALAPPDATA%\Readerka\startup.log`.

Личная библиотека хранится в `%LOCALAPPDATA%\Readerka`. Она не находится рядом с программой и сохраняется при замене папки программы. Одновременно можно открыть только один экземпляр с этой библиотекой. Для отдельной тестовой библиотеки: `Readerka.cmd --data-dir "D:\Readerka test"`. Не указывайте папку данных Android. PDF или ZIP можно перетащить на Readerka.cmd.

Это переносимый пакет ZIP с запуском через CMD, не установщик MSI. Подробные результаты проверок и границы проверки Windows приведены в [DESKTOP_VALIDATION.md](DESKTOP_VALIDATION.md).

## Перенос планшет → ПК → планшет

1. В Readerka Preview на планшете сохраните открытые черновики, затем **Настройки → Резервная копия ZIP**.
2. Перенесите ZIP на компьютер любым удобным способом.
3. На ПК: **Файл → Импорт ZIP**. Посмотрите различия и выберите способ импорта.
4. Настройте книги, папки, заметки, цитаты и конспекты.
5. На ПК: **Файл → Экспорт ZIP**. Экспорт сначала сохраняет все открытые черновики.
6. Для обновления существующих записей установите **Android 0.9.1 Preview** поверх Preview 0.9, не удаляя приложение. На планшете: **Настройки → Восстановить ZIP → Обновить из архива**.

**Сохранить местные** добавляет новые записи и сохраняет совпадающие идентификаторы в местном состоянии. **Обновить из архива** заменяет совпадающие записи и их папки/теги, оставляя прочие местные данные. **Заменить библиотеку** также удаляет записи, отсутствующие в архиве, и требует отдельного подтверждения. Смешение несовместимых деревьев папок отклоняется до записи данных; в таком случае можно выбрать другую политику или полную замену.

Перед любым подтверждённым импортом создаётся ZIP текущей библиотеки. На ПК он находится в `%LOCALAPPDATA%\Readerka\backups`; его можно импортировать обычной командой. На Android резервные копии доступны в **Настройки → Автоматические резервные копии перед переносом**. Резервные копии не удаляются автоматически.

ZIP версии 4 совместим с Android 0.9; принимаются также версии 1–3. Старая Android 0.9 может импортировать данные в пустую библиотеку, но отклоняет изменённые записи с совпадающим ID: для обратного обновления используйте 0.9.1. Пакет `org.readerka.preview`, прежний сертификат и Room schema 4 сохранены. Оригинальный Readerka 0.5 — отдельное приложение: переносите данные через ZIP.

Сохраняются UUID, сами PDF, положение чтения, прямоугольники выделений, комментарии, форматирование, абзацные ссылки, связанные книги, теги, папки, закладки и версии записей. Формат ZIP не содержит состояния окон и несохранённых черновиков: на ПК они сохраняются перед экспортом; на Android 0.9 обычные заметки нужно сохранить вручную. Окна, выделение редактора и черновики ПК сохраняются локально. Не переносите SQLite-файл между устройствами. Это ручной обмен архивами; автоматической синхронизации нет.

## Работа на компьютере

- Проводник и основная область показывают отдельные папки PDF, заметок/цитат и конспектов. Двойной щелчок или Enter открывает папку; поиск включает вложенные папки. «Все записи» включает плоский список.
- **Свойства** записи содержат категорию, тип, маркер, теги, несколько папок и связанные книги. Конспекты можно отвязать от книги, связать с несколькими или создавать по теме.
- Редактор поддерживает жирный, курсив, подчёркивание, заголовки, цитатные блоки, списки, код, разделители, отмену/повтор и форматированный буфер обмена внутри Readerka. **Читать** открывает просмотр с возможностью сворачивать разделы. **Версии** создаёт контрольные точки и восстанавливает предыдущий текст.
- **Вставить…** открывает каталог с поиском и фильтрами. Можно сделать ссылку на выделенном слове, вставить карточку-ссылку или содержимое с ссылкой на источник, в том числе выбранный фрагмент. Отдельно доступны ссылки на страницу PDF. Ctrl+щелчок открывает ссылку в редакторе; в просмотре — обычный щелчок.
- PDF поддерживает выделение мышью, просмотр «Текст» для выделения только клавиатурой, двойной щелчок по слову, цитаты/комментарии, добавление в уже существующий конспект, масштаб, поиск по всем страницам, закладки и папки материалов книги. Перевод открывает внешний Google Translate и требует сети. Для скана без текстового слоя доступно чтение и создание закладок; OCR не добавлен.
- В меню ⋮ вкладки можно закреплять, переставлять и переносить между областями. Закрытие последней правой вкладки убирает пустую область, в том числе в полном экране. Граница перетаскивается до края; видимая команда закрытия и готовые пропорции доступны без перетаскивания. Настройки также меняют ориентацию областей, тему и плотность.
- Фильтры записей включают источник, тип, маркер, тег и дату; сортировка — дату, книгу, автора, страницу или тип. Теги можно переименовывать и удалять. Экспорт доступен в Markdown, CSV и Obsidian Vault с PDF.

## Горячие клавиши

Полный список создаётся из тех же команд, которые обслуживают клавиатуру: откройте **F1 → Справка**. Все действия доступны и через меню.

| Клавиши | Действие |
|---|---|
| Ctrl+O / Ctrl+N / Ctrl+Shift+N | Добавить PDF / заметку / конспект |
| Ctrl+S / Ctrl+Shift+S | Сохранить запись / всё |
| Ctrl+Shift+O / Ctrl+Shift+E | Импорт / экспорт ZIP |
| Ctrl+B / Ctrl+I / Ctrl+U | Жирный / курсив / подчёркивание |
| Ctrl+K / Ctrl+Shift+K | Ссылка / каталог вставки |
| Ctrl+Alt+1…3 / Ctrl+Alt+0 | Заголовки / абзац |
| Ctrl+Z / Ctrl+Shift+Z | Отмена / повтор в редакторе |
| Ctrl+Shift+P | Просмотр записи |
| Ctrl+F / Alt+Enter | Поиск / свойства |
| Ctrl+D | Закладка PDF |
| Ctrl+Alt+R / Ctrl+Shift+Q / Ctrl+Alt+A | Текст PDF / цитата из выделения / в конспект |
| Ctrl+Alt+B / Q / C | Закладки / цитаты / конспекты книги |
| Ctrl+Alt+S / Ctrl+Alt+W | Две области / свернуть в одну |
| Ctrl+Alt+O / F6 | Открыть выбранное справа / сменить область |
| Ctrl+W / F11 / F1 | Закрыть вкладку / полный экран / справка |
| Alt+Left / Right / Up | История источников / вернуться к записи |
| Ctrl+Shift+F / Ctrl+Alt+T | Создать папку / управление тегами |
| Ctrl+C / X / V / A | Копировать / вырезать / вставить / выделить всё |
| Tab / Shift+Tab / Shift+F10 | Переход / обратно / контекстное меню |

## Сборка из исходников

JDK 17; для упаковки ZIP — Python 3 и curl. Gradle wrapper входит в репозиторий. Для Android требуется Android SDK 35; задачи только desktop можно запускать с `--configure-on-demand`.

```bash
./gradlew :shared:test :desktop:test --configure-on-demand
./gradlew :desktop:run --configure-on-demand
bash scripts/build-windows.sh
```

На подготовленной облачной машине сначала выполните `source scripts/cloud-env.sh`. Для настоящих Swing/Robot тестов нужен графический экран: `bash scripts/cloud-desktop-display.sh`, проверка `DISPLAY=:98 xdpyinfo`, затем `DISPLAY=:98 ./gradlew :desktop:test`. Без экрана GUI тесты отмечаются как пропущенные, а не как успешно проверенные. Windows workflow запускает те же тесты и собирает ZIP на windows-latest. Проверяйте результат конкретного запуска Actions.
