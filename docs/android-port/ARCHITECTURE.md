# Архитектура Android-порта

`app/` остаётся единственным Android-приложением. Gradle подключает неизменённый `windows/shared` как `:shared`: DTO, RichText/UTF-16 операции, папки, ссылки, граф сохранённых фактов, поля/сборка и ZIP/merge/export имеют одну реализацию. Swing, AWT, JDBC и DPAPI не входят в Android. `windows/` не изменён.

Android-адаптеры: Room с явной миграцией 4→5; PdfRenderer/PDFBox Android; native EditText внутри Compose; SAF; AES-GCM/Keystore. Поля сохраняются целиком в одной JSON-строке Room. Вкладки/черновики, выделения/масштаб PDF, режим/выбор поля и вид графа сохраняются локально через DataStore и не входят в перенос библиотеки. Canvas и доступный список используют те же ID объектов, включая несколько размещений одной записи.

Рабочее пространство восстанавливается до открытия команд интерфейса и обработки входящего deep link. Счётчик страниц PDF закреплён отдельно от прокручиваемых команд; палитра выделения имеет отдельную строку. Выбранная вкладка прокручивается в видимую область. Обновление сохранённого выделения не отменяет незавершённый сенсорный жест.

ZIP сначала проходит общую проверку, проверку каждого PDF и сравнение с текущим снимком. Перед применением сохраняется резервный ZIP. Замена файлов использует Android-адаптер настольного журнала; квитанция фиксируется в той же Room-транзакции, что и новая библиотека. При запуске квитанция определяет завершённое применение или откат файлов. Повторная проверка снимка предотвращает применение сравнения к уже изменённой библиотеке.

Конвертеры создают managed PDF со стабильной пагинацией; исходный PDF копируется без изменения. DjVu/TIFF собираются из приложенных и проверенных исходников для arm64-v8a/x86_64. Текстовый конвертер использует DejaVu и статический Noto CJK с отдельными glyph IDs для Unicode-алиасов: иначе PDFBox мог бы возвращать радикал вместо исходного иероглифа. Все лицензии включены в assets и THIRD_PARTY_NOTICES.

HTTP/PKCE код Dropbox генерируется из неизменённого настольного протокола с заменой недоступного на API 28 чтения потока. Передача запускается только командами пользователя; upload проверяет ревизию и хеш, download ведёт в общий preview. Токены шифруются отдельно от базы библиотеки. Реальное подключение аккаунта требует отдельной проверки.

Программный эмулятор без KVM подтверждает функции данных и часть GUI, но сбои системного WindowManager/IME ограничивают полный графический прогон. PortXmlListener сохраняет результаты по каждому тесту и отличает завершённый прогон от прерванного. См. STATUS.md для фактических результатов и ACCEPTANCE.md для команд и физической проверки Huawei.

Запрошенная PDF-страница и смещение сохраняются во вкладке до загрузки движка; затем страница ограничивается фактическим числом страниц. Восстановление нового ViewModel не зависит от первого события прокрутки UI.

Native EditText не переустанавливает одинаковый шрифт, цвет и spans при независимых обновлениях Compose; форматирование обновляется при изменении RichText/цвета темы или реальном редактировании. Размер задаётся в пикселях LocalDensity, поэтому системный fontScale применяется один раз.
