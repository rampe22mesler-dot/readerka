# Readerka

Нативное офлайн-приложение для чтения PDF и независимой организации цитат и заметок. Kotlin, Jetpack Compose, Material 3, Room и DataStore. Ориентир — **Huawei MatePad 11.5 S / HarmonyOS 4.2**, с поддержкой Android APK. Минимальный Android API — 28.

Для библиотеки не нужны аккаунты, Google Play Services или сервер. Чтение, цитаты, закладки и экспорт работают офлайн. Только встроенное окно Google Переводчика использует интернет и отправляет выбранный для перевода текст Google. Библиотека при первом запуске пустая; все тематические папки создаёт пользователь.

## Папки в каталоге 0.9.0 — Preview

[Скачать Readerka 0.9.0 Preview — страница APK](https://github.com/rampe22mesler-dot/readerka/blob/main/downloads/readerka-0.9.0-preview.apk) · [Руководство](docs/CONSP_GUIDE.md) · [SHA-256](downloads/SHA256SUMS.txt)

Версия 0.9 сделана на основе **0.7**. Чтобы скачать из закрытого репозитория, войдите в GitHub с доступом и нажмите **Download raw file / View raw** на странице APK. Устанавливайте поверх Readerka Preview 0.6–0.8, без удаления приложения: пакет и ключ подписи сохраняются, внутренний номер сборки — 9.

- **Папки открываются непосредственно в основном каталоге** PDF, заметок/цитат и конспектов. Внутри видны подпапки и записи текущей папки; на верхнем уровне — корневые папки и записи без папки. Выбор папки в проводнике открывает то же содержимое справа. Стрелка рядом с папкой отдельно раскрывает дерево проводника.
- Путь над списком и **«На уровень выше»** возвращают к родителю. Кнопка **«Все записи» / «Все конспекты» / «Все документы»** включает общий список; **«По папкам»** возвращает к открытому месту. Поиск ищет в текущей папке и подпапках; в корне и общем списке — во всём соответствующем каталоге. Фильтры уточняют записи, а их сброс сохраняет открытую папку.
- У **конспектов собственные папки**, независимые от заметок и цитат. Выбор папок в свойствах, назначение через проводник, создание и пакетные действия используют только нужный раздел. Конспект можно по-прежнему поместить в несколько своих папок, не копируя запись.
- Создание в открытой папке сразу назначает её новой записи. ⋮ и долгое нажатие на папку позволяют создать подпапку, переименовать, переместить или удалить её. Пустая папка показывает понятную подсказку.
- При обновлении старое общее дерево остаётся у заметок/цитат и получает независимую копию у конспектов, включая пустые папки и вложенность. Назначения конспектов переходят в их дерево. Текст, ссылки, теги, книги, версии и черновики сохраняются; записи не дублируются. Папки новых разделов после этого можно менять независимо.

Room и резервные ZIP переходят к версии 4; импорт читает ZIP версий 1–4. Подробные проверки и ограничения: [VALIDATION.md](docs/VALIDATION.md). [Снимок каталога папок](docs/screenshots/readerka-0.9-folders.png).

### Что изменилось

- Единое рабочее пространство с нейтральными светлой/тёмной темами, фиолетовым акцентом, тонкими разделителями и авторскими контурными значками. У значков есть подписи для доступности, подсказки, состояния наведения и клавиатурного фокуса.
- Общие вкладки PDF и заметок в двух независимых областях. Через ⋮ или долгое нажатие доступны закрепление, закрытие, порядок и **Открыть справа**. Можно открыть две заметки, два PDF или два места одного PDF. Закрытие вкладки сохраняет документ и черновик.
- Проводник показывает PDF и общие папки заметок с вложенными записями. В разных ветках это ссылки на одну каноническую запись. Меню позволяет создавать папки и заметку в выбранной папке, переименовывать на месте, перемещать и добавлять назначения. Удаление из одной ветки сохраняет другие назначения. Общие папки отличаются от папок цитат внутри PDF.
- Для PDF оставлены вкладки и одна основная панель. Постоянная инструкция перенесена в справку; номер больше не повторяется над каждой страницей. Действия выделения появляются поверх PDF и не меняют высоту чтения. Перевод открывается поверх приложения, а **В конспект** вставляет цитатный блок со ссылкой на источник и страницу.
- Конспект открывается документом пространства. Заголовок и текст занимают основную область; тип, цвет, теги, источник и назначения находятся в сворачиваемых свойствах. Markdown-просмотр показывает заголовки, списки, задачи, выделение, цитаты, код и ссылки, сохраняя исходный текст без изменений. Изображения пока показываются текстовым обозначением.
- Размеры проводника, структуры PDF и областей можно менять касанием ручки либо через **Области и размеры**: слайдеры, готовые пропорции, стандартные размеры. Выбор сохраняется после запуска. На узком экране области располагаются вертикально; при экранной клавиатуре активная область получает всё доступное место.
- Каталог показывает компактные фрагменты; развёрнутый вид доступен отдельной кнопкой. Активные фильтры видны и сбрасываются. Обычная/компактная плотность и масштаб текста доступны в настройках; области касания остаются не меньше 48 dp.
- **Ctrl+P** — команды, **Ctrl+O** — источники, **Ctrl+N** — заметка, **Ctrl+S / Ctrl+Enter** — сохранение, **Ctrl+B** — проводник, **Ctrl+Tab / Ctrl+Shift+Tab** — вкладки активной области, **Ctrl+W** — закрытие, **Alt+← / Alt+→** — история. **Tab / Shift+Tab** перемещают фокус; Enter активирует кнопки. Стрелки в редакторе двигают курсор, в активном PDF — страницы.

Все действия доступны касаниями и видимыми меню. Перетаскивание мышью имеет альтернативы через **Переместить**, **Добавить в папку**, **Открыть справа**, **Изменить порядок**. База Room остаётся версии 2; прежние цитаты, папки, теги, назначения, резервные архивы и экспорт Obsidian сохраняются. Рабочее пространство мигрирует аддитивно, старые черновики остаются на диске.

## Изменения в 0.5.0

- Редактор заметки и комментария к цитате располагается справа от PDF при достаточной ширине. На узком экране и в общем каталоге он открывается отдельным окном. Стрелки двигают курсор в редакторе, а при фокусе на PDF перелистывают страницы.
- Изменения автоматически сохраняются как **черновик**: заголовок, текст, тип, цвет, теги и назначения в нескольких общих/внутренних папках. Статус «Черновик сохранён» означает завершённую запись на диск. Кнопка закрытия сохраняет незавершённую работу; кнопка **Сохранить** обновляет одну каноническую запись.
- **Черновики** в верхней панели позволяют продолжить закрытую запись. Активный редактор восстанавливается после повторного запуска. Удаление черновика требует подтверждения и не удаляет уже сохранённую запись. Черновики локальны и не включаются в экспорт и резервные ZIP: перед переносом библиотеки сохраните нужные записи.
- История переходов между источниками, цитатами, закладками и результатами поиска хранит до 100 мест чтения. **Alt+← / Alt+→** и кнопки верхней панели возвращают документ, страницу и положение прокрутки. Обычное листание обновляет текущее место, не создавая запись на каждую страницу.
- **Ctrl+P** открывает команды и поиск источников, цитат, закладок и черновиков; **Ctrl+O** — только источники с недавними сверху. Стрелки выбирают результат, Enter открывает, Esc закрывает. Команды также доступны через значок поиска в верхней панели.
- **Ctrl+N** — новая заметка, связанная с текущим PDF при чтении; **Ctrl+S / Ctrl+Enter** — сохранить редактор; **Ctrl+F** — поиск в PDF. Через команды доступны страницы, цитаты, закладки, полноэкранный режим и панели.
- Схема Room остаётся 2; существующие записи и несколько назначений цитаты сохраняются.

Снимок редактора с синтетическим PDF: [Readerka 0.5.0](docs/screenshots/readerka-0.5-editor.png). Демонстрационных документов и черновиков в APK нет.

## Изменения в 0.4.0 (история)

- В разделе заметок левая панель показывает дерево папок заметок. Папки создаются независимо от цитат: **+** — новая папка на верхнем уровне; **⋮ → Создать подпапку** — новая папка в выбранной ветке. Там же доступны переименование, перемещение через выбор родителя и удаление без удаления записей.
- В PDF панели цитат и закладок показывают такие же деревья с созданием папок и подпапок. Папки каждого PDF и общие папки заметок сохраняют независимость.
- Стрелки сворачивают/разворачивают ветки. Поиск папок показывает совпадения вместе с родителями. Выбор родительской папки в каталоге включает её подпапки.
- Редактор цитаты открывает дерево с флажками: отметьте несколько папок, нажмите **Применить**, затем **Сохранить**. Это одна запись с несколькими принадлежностями; снятие одного флажка сохраняет остальные назначения. Пакетное добавление тоже допускает несколько папок.
- Фильтр папки и выбор родителей теперь используют дерево. Для источников и тегов есть отдельный поиск и прокручиваемое окно; длинные названия занимают максимум две строки. Пять последних открытых источников показываются сверху. Есть сброс всех фильтров.
- Существующая база, цитаты и их принадлежности сохраняются; схема Room остаётся 2.

Снимок панели папок с тестовой записью: [Readerka 0.4.0](docs/screenshots/readerka-0.4-folder-workspace.png). Тестовых папок и документов в APK нет.

## Изменения в 0.3.0 (история)

- Рабочее пространство в стиле Obsidian: узкая лента навигации, дерево PDF и папок слева, вкладки открытых документов сверху, структура текущего PDF справа.
- Библиотеку можно сворачивать; на узком экране она открывается поверх содержимого. Панель цитат и закладок располагается рядом с PDF, когда хватает места.
- Светлая и тёмная темы с приглушённым фиолетовым акцентом, компактными вкладками и тонкими разделителями.
- Вкладки сохраняют страницы документов и переживают пересоздание окна. Закрытие вкладки не удаляет документ.
- Ctrl+B — библиотека, Ctrl+Tab / Ctrl+Shift+Tab — следующая / предыдущая вкладка, Ctrl+W — закрыть текущую. Стрелки, Page Up / Down и Home / End сохраняют управление страницами.
- **Перевести** открывает официальный Google Переводчик в окне поверх PDF. Текст передаётся автоматически через URL и сразу копируется в буфер обмена. Сервисы Google Play и отдельное приложение переводчика не нужны. Для загрузки страницы Google необходимы интернет и системный WebView.
- Удержание любой буквы сначала выделяет целое слово. Перетаскивание расширяет выделение; границы по-прежнему можно поправить ручками.

## Изменения в 0.2.0 (история)

- Кнопки **Цитаты** и **Закладки** прямо в PDF открывают структуру текущего документа. В широком окне панель остаётся рядом с текстом.
- Нажмите на сохранённую подсветку, затем **Удалить** и подтвердите удаление. В панели цитат удаление тоже доступно.
- Стрелки клавиатуры, Page Up / Page Down, Home / End перелистывают страницы. Работают и при фокусе на самой PDF-странице.
- Касание средней части PDF или счётчика страниц открывает полосу с ползунком; её стрелки листают по одной странице, номер открывает ввод страницы.
- Закладки открывают страницу и сохранённое положение. Их можно редактировать и вкладывать друг в друга.
- У каждого PDF — свои вложенные папки цитат и закладок. Папки цитат назначаются в редакторе цитаты; папка и родитель закладки — в редакторе закладки. Глобальные коллекции остаются независимыми.
- Изображение страницы загружается независимо от текстового слоя; переработаны повторный показ страниц и переходы при изменении размеров окна.
- **Перевести** при выделении текста открывает Google Переводчик в браузере: язык определяется автоматически, перевод на русский. Для этой внешней функции нужен интернет.
- База обновляется без удаления данных. Восстанавливаются резервные копии 0.1.0; новые копии и Obsidian ZIP сохраняют структуру внутри PDF.

Подробные проверки и оставшиеся ограничения: [docs/VALIDATION.md](docs/VALIDATION.md).

## Возможности

- Импорт одного или нескольких PDF через системный выбор файлов; управляемые локальные копии и исходные имена.
- Независимые вложенные папки библиотеки и коллекции заметок; создание, переименование, перемещение и удаление папок без удаления их содержимого.
- Настоящая отрисовка PDF, вертикальная прокрутка, масштабирование двумя пальцами, режимы по ширине / целой странице, полноэкранное чтение, поиск текста, закладки и сохранение позиции.
- Выделение текста удержанием и перетаскиванием, корректируемые границы, копирование, шесть независимых цветов. Подсветка сохраняется в базе, оригинал PDF не меняется.
- Комментарии к цитатам и самостоятельные заметки; восемь типов, теги, цвет, несколько коллекций без копирования записи.
- Общий каталог: поиск по тексту, источнику, автору и тегам; комбинированные фильтры, сортировка, множественный выбор, пакетное добавление в папку, смена цвета/типа, добавление тегов и удаление с подтверждением.
- Переход из каталога к фактической странице и положению цитаты; панель заметок рядом с PDF в широком окне.
- Ручные метаданные документа, теги документов и управление тегами.
- Полный ZIP для Obsidian: иерархии, пустые папки, канонические Markdown-заметки, ярлыки коллекций, метаданные, закладки, исходные имена и 1-based страницы. PDF включаются по умолчанию, опцию можно отключить.
- Markdown/CSV всех записей, выбранной папки или выбранных записей.
- Версионированная резервная копия с PDF и SHA-256; проверка перед восстановлением, транзакционное добавление, защита существующих записей от конфликтующего перезаписывания.
- Светлая, тёмная и системная темы; масштаб текста, цвет выделения по умолчанию; русский интерфейс в string resources.

## Открыть в Android Studio

1. Откройте папку проекта `readerka` командой **Open**.
2. Используйте JDK 17 для Gradle.
3. Установите Android SDK Platform 35 и Build Tools 35.0.0 через SDK Manager.
4. Выполните Gradle Sync. Android Studio создаст локальную конфигурацию SDK.
5. Выберите `app` и запустите на Android 9+ либо планшете с поддержкой APK.

Сборка из терминала:

```bash
./gradlew assembleDebug
# Отдельное безопасное приложение с новым ключом:
./gradlew assembleDebug -PreaderkaPreview=true
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Это debug-сборка; выпускная подпись для магазина пока не настроена. Локальный ключ этой среды не совпадает с ключом 0.5.0: обычный developer APK не является совместимым обновлением. Для установки рядом используйте `-PreaderkaPreview=true`. Для установки на MatePad откройте APK и подтвердите стандартный запрос системы на установку из выбранного источника. Работоспособность на конкретном MatePad требуется проверить отдельно.

## Ограничения

- Выделение ограничено одной страницей; OCR и ввод пароля для зашифрованных PDF отсутствуют.
- Порядок извлечения текста зависит от текстового слоя PDF. Сложные колонки, нестандартные шрифты и RTL нужно проверить на реальных академических документах.
- Работа со стилусом использует стандартные Android pointer events, но физический M-Pencil не тестировался.
- Obsidian-ссылки на страницы имеют вид `[[путь.pdf#page=N]]`. Структура архива проверена автоматически, взаимодействие в настоящем Obsidian требует ручной проверки; синхронизация и обратный импорт Vault не реализованы.
- Связи между заметками и drag-and-drop пока не реализованы.
- Длительная операция выполняется в ViewModel, а не в WorkManager: завершите экспорт перед принудительным закрытием приложения.
- Восстановление добавляет данные и отклоняет конфликты, а не перезаписывает изменённую библиотеку. Поддерживаемый размер распакованной резервной копии — до 2 GiB.
- Синтетические многостраничные PDF проверяют доступ к страницам; они не заменяют испытаний скорости на тяжёлых сканах или реальном планшете.
