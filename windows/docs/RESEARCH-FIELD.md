# Исследовательское поле

Создание: «Файл → Создать исследовательское поле», кнопка со связью на
левой полосе или меню проводника. Поля перечислены в отдельном разделе.
Вкладка открывается рядом с книгой; её можно переносить между областями.

Выделение PDF: кнопка «Добавить на исследовательское поле», контекстное
меню или Ctrl+Alt+L. При совпадении книги, страницы и диапазона символов
предлагается использовать сохранённую цитату. Отмена выбора поля не
создаёт новую цитату. Для записи команда доступна в проводнике, материалах
книги и через Ctrl+Alt+L в открытом редакторе. Панель материалов передаёт
на поле ID цитат при перетаскивании; папочные назначения сохраняются.

Карточки содержат цитату, автора, источник, страницу и общий комментарий.
«Применение в этом проекте» хранится только в размещении. Заметка и тезис
создают обычные записи библиотеки, доступные существующему редактору.
Одна запись может иметь несколько размещений в одном или разных полях.
Изменения исходной записи отражаются во всех её карточках.

Перемещение начинается только на заголовке. Текст внутри карточки можно
выделять и копировать; прокрутка позволяет читать длинные фрагменты.
Нижний угол меняет размер. Ctrl/Shift и заголовок изменяют множественный
выбор, рамка на пустом месте выбирает несколько карточек. Их заголовок
перемещает весь выбор. Alt+перетаскивание, средняя кнопка и колесо
панорамируют поле; Shift+колесо перемещает его горизонтально,
Ctrl+колесо меняет масштаб вокруг курсора. «Всё» и «Выбранное» подгоняют
материалы под окно. Координаты хранятся в системе поля; масштаб окна их
не изменяет. Диапазон масштаба: 1–300%.

«Связь» задаёт источник, получателя, тип и подпись. Линии идут по отдельным
каналам ниже карточек, стрелка отмечает получателя. Двойной щелчок по
линии или подписи позволяет изменить или удалить связь. «Группа»
объединяет выбор; заголовок группы перемещает её целиком, правая кнопка
переименовывает или расформировывает группу. Меню карточки добавляет
выбор в существующую группу либо снимает назначение.

«Открыть источник» показывает книгу в соседней области и выделяет
сохранённый Anchor. «Открыть запись» открывает общий редактор.
«Убрать карточку с поля · сохранить запись» удаляет размещение и его
связи. Запись остаётся в библиотеке. Удаление самой записи в проводнике
удаляет её размещения во всех проектах; отдельное подтверждение это
указывает. Удаление поля также сохраняет записи.

Отмена/повтор охватывают размещения, размеры, комментарии проекта,
связи, группы и последовательность. История содержит до 100 действий
открытой вкладки и заканчивается при её закрытии. Созданная запись
остаётся в библиотеке при отмене её добавления на поле. Изменение вида
сохраняется отдельно и не заполняет историю. Жест сохраняется при
отпускании мыши; масштаб колеса — через 300 мс или при закрытии.

Для сборки конспекта выбираются карточки и существующий конспект.
В диалоге явно подтверждается порядок; «Выше» и «Ниже» его меняют.
Результат добавляется в конец конспекта ссылками либо содержимым с
ссылками на источники. Содержимое включает проектный комментарий;
порядок сохраняется для следующей сборки. Вставка сохраняет связи
Readerka и список книг, а предыдущую версию конспекта — штатная история.
Геометрическое положение карточек не задаёт последовательность.

# Хранение и обратимость

Формат библиотеки и ZIP расширен до версии 5. Поля входят в LibrarySnapshot
и сохраняются штатной SQLite-транзакцией. ZIP включает поля, размещения,
связи, группы, порядок, комментарии и вид; открытые вкладки по-прежнему
локальны. Проверка архива отвергает отсутствующие записи/карточки,
повторяющиеся ID, неправильные координаты и повреждённые ссылки.
Конфликт ZIP разрешается целиком для поля по его ID; связи разных версий
одного поля не смешиваются.

Архивы 1–4 принимаются с явной миграцией. При первом открытии старой
локальной библиотеки Readerka до изменения формата создаёт в её `backups`
три файла `before-research-v5-<время>`: ZIP прежней версии, точную SQLite
копию и исходный JSON рабочего пространства. Ошибка резервирования
останавливает миграцию. Личная библиотека не использовалась при разработке.

Исходники и установленные JAR до изменения находятся в
`.local-backups/research-before`. Для возврата закройте Readerka и локальные
Java-сборки, затем выполните из этой папки:

```powershell
.\Restore-Research.ps1
```

Если библиотека уже открывалась новой версией, укажите именно эту
библиотеку и точный путь к её SQLite-копии до миграции:

```powershell
.\Restore-Research.ps1 -LibraryDirectory 'C:\путь\к\библиотеке' -DatabaseBackup 'C:\путь\к\библиотеке\backups\before-research-v5-ВРЕМЯ.sqlite'
```

Сценарий восстанавливает прежние PDF из соответствующего ZIP, всю SQLite
библиотеку вместе с рабочим пространством, исходники и JAR. Открытая
библиотека блокирует восстановление. Состояние перед откатом сохраняется
в `.local-backups/before-research-rollback-*`. `-LibraryOnly` восстанавливает
только указанную библиотеку; запуск новой версии после этого снова
выполнит миграцию. После отката исходников чистая сборка выполняется
через `Local.ps1 -Action Build -Rebuild`.

Прежние сборки Windows и Android не читают формат 5. Откат библиотеки
возвращает состояние до миграции, включая прежние записи и расположение
вкладок; изменения, сделанные после неё, остаются только в копии перед
откатом. Для их восстановления потребуется новая версия.

# Проверка

```powershell
.\Local.ps1 -Action Build
.\Local.ps1 -Action Test
.\Local.ps1 -Action Test -Ui -DesktopTests 'org.readerka.desktop.ResearchFieldUiTest'
.\Local.ps1 -Action Run
```

Фильтр DesktopTests ограничивает только desktop-тесты, shared-тесты
сохраняют стандартный состав. Новый Swing-сценарий использует события
Swing и `printAll`, временные библиотеки и два синтетических PDF; он
не использует нативный Robot. Снимки находятся в
`source/desktop/build/screenshots/research-field-{light,dark,narrow}.png`.

Проверяются два проекта с одной записью, геометрия после открытия заново,
связи после движения и перезапуска, независимость проектного комментария,
возврат к выделению PDF, сохранность записи после удаления карточки,
отмена/повтор, заметка, тезис, повторное использование цитаты, передача
ID из материалов, создание поля и сборка с сохранением ссылок.
Тесты хранилища дополнительно проверяют ZIP, миграцию, конфликт полей,
точную SQLite-копию до миграции и отказ при повреждённых данных.

Ограничения: группы имеют один уровень и одно назначение на карточку;
сборка добавляет текст в конец существующего конспекта; совпадение цитат
определяется по Anchor, без поиска приблизительно похожего текста.
На очень плотном поле линии могут пересекаться; автоматического
разведения пересечений нет. Подгонка ограничена минимальным масштабом 1%.
Нативное перетаскивание между окнами и полный Robot-прогон требуют
отдельной проверки на доступном рабочем столе Windows.
