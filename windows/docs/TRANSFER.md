# Ручной перенос между устройствами

Откройте «Файл → Синхронизация» в меню приложения или кнопку
«Синхронизация…» в настройках. «Выгрузить данные…» сохраняет полный
снимок библиотеки в `Readerka-transfer-ГГГГММДД-ЧЧММСС.zip`.
Черновики перед выгрузкой сохраняются в записи.

Перенесите ZIP на другое устройство, откройте Readerka и нажмите
«Загрузить данные…». До применения архив проходит проверку структуры,
SHA-256 и файлов PDF; окно сравнения показывает новые и изменённые объекты,
а также объекты, существующие только в местной библиотеке. Изменения
содержимого PDF показываются отдельно от изменений свойств книги.

| Режим | Совпадающие ID | Новые ID | Отсутствуют в ZIP |
|---|---|---|---|
| Сохранить местные | Сохраняются местные версии | Добавляются | Сохраняются |
| Обновить из архива | Заменяются версиями из ZIP | Добавляются | Сохраняются |
| Заменить библиотеку | Принимается весь снимок ZIP | Добавляются | Удаляются после подтверждения |

Выбранный режим применяется ко всей загрузке. Автоматического выбора
более свежей версии и объединения отдельных фрагментов текста нет.
Повторный импорт распознаёт материалы по ID; одинаковое название
само по себе не объединяет независимо созданные материалы. Теги с
одинаковым именем объединяются.

Перед применением создаётся `backups/before-import-*.zip` внутри
библиотеки. Путь показывается после завершения. Для отката загрузите
эту копию и явно выберите «Заменить библиотеку». Отмена сравнения
оставляет библиотеку без импортированных изменений; редакторские
черновики, сохранённые перед сравнением, остаются сохранёнными.

## Шаблон выгрузки

Используется существующий ZIP формата 5, без отдельного сетевого протокола:

```text
manifest.json       версия формата и SHA-256 каждого файла
library.json        записи, книги, папки, теги и отношения по постоянным ID
pdfs/<storedName>   PDF каждой книги
```

Выгрузка переносит цитаты и выделения, заметки с форматированием, конспекты,
закладки, положения чтения, историю версий записей, папки и назначения,
исследовательские поля с карточками, группами и связями. Исходные EPUB,
DOCX и другие файлы после преобразования в PDF, личные настройки интерфейса
и открытые вкладки в архив не входят. Загрузка закрывает открытые вкладки.

На принимающем устройстве нужна Readerka с поддержкой формата 5;
прежние Windows/Android его не читают. Этот этап реализован в локальной
desktop-сборке; Android-модуль локально не собирается и не обновляется.

Обмен выполняется вручную. Фонового наблюдения за папками,
автоматического распространения удалений и шифрования архива нет.
Формат ограничивает распакованные данные двумя ГиБ, один PDF — одним ГиБ.

## Dropbox

В окне «Синхронизация» откройте вкладку Dropbox. Подключение работает
через аккаунт и официальный API, без установленной программы Dropbox.
Google Диск в этой версии не подключён.

Однократная настройка приложения:

1. Откройте [Dropbox App Console](https://www.dropbox.com/developers/apps)
   кнопкой в Readerka и создайте приложение: Scoped access → App folder.
2. На вкладке Permissions включите `account_info.read`,
   `files.metadata.read`, `files.content.read`, `files.content.write`,
   затем нажмите Submit.
3. Скопируйте App key из Settings в Readerka. App secret и Redirect URI
   не нужны. Нажмите «Войти в Dropbox…», разрешите доступ в системном
   браузере и вставьте выданный одноразовый код в Readerka.
4. Для обмена между устройствами используйте тот же App key и аккаунт.
   Разные приложения Dropbox имеют разные папки и копии библиотеки.

Вход использует [OAuth PKCE](https://docs.dropboxapi.com/dropbox-api/docs/oauth).
Refresh token хранится в `dropbox-account.dpapi` внутри библиотеки,
зашифрованный Windows DPAPI для текущего пользователя. Он не входит
в экспорт ZIP; App key и состояние подключения также не переносятся.
На другом устройстве потребуется отдельный вход. «Отключить на этом
устройстве» удаляет местный токен; облачный ZIP сохраняется. Для полного
отзыва доступа удалите приложение в настройках подключённых приложений Dropbox.

«Выгрузить в Dropbox…» сначала запрашивает подтверждение отправки полной
библиотеки. Если `Readerka-library.zip` уже существует в папке приложения,
появится отдельное подтверждение замены с датой и размером копии.
Отмена не отправляет библиотеку. После подтверждения сохраняются черновики,
создаётся ZIP и передаётся частями. Операция привязана к версии облачного
файла: изменение копии другим устройством останавливает замену с ошибкой.
Автоматического повтора и автоматического разрешения конфликтов нет.

«Загрузить из Dropbox…» запрашивает подтверждение, скачивает конкретную
версию ZIP, проверяет размер и контрольную сумму Dropbox. Затем действует
обычное сравнение и импорт, описанные выше: выбор режима, проверка ZIP/PDF,
резервная копия и отдельное подтверждение полной замены. Скачивание само
по себе не меняет записи библиотеки. Временные ZIP удаляются после операции
или ошибки. Обрыв питания может оставить временный ZIP в папке библиотеки.

При сохранении записей, запуске и закрытии Readerka запросов к Dropbox нет.
Обновление токена выполняется только для запрошенной вручную операции.
Архив не шифруется; предел скачиваемого ZIP — 3 ГиБ с учётом упаковки,
ограничения распакованных данных остаются прежними.
