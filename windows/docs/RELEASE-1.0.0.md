# Readerka 1.0.0: проверка выпуска

Целевая платформа: Windows 10/11 x64. Исходники: самостоятельный проект desktop/shared, Kotlin 2.1.20, JDK 17.0.20.1+1. Сборка выполняется локально без скачивания Gradle-зависимостей.

Версия JAR, заголовок приложения и нативный установщик используют 1.0.0 из gradle.properties. Установщик MSI устанавливает приложение для текущего пользователя, создаёт ярлыки и запись удаления; стабильный upgrade UUID сохранён в scripts/Build-Release.ps1. Каталог программы по умолчанию: %LOCALAPPDATA%\ReaderkaApp. Личная библиотека не входит в MSI и остаётся отдельно от каталога программы.

Офлайн-сборка Local.ps1 -Action Build и проверка Local.ps1 -Action Test завершились без ошибок. Пройден 121 тест (68 shared, 53 desktop), 19 интерфейсных тестов пропущены. Отдельно прошли DropboxUiTest, TransferUiTest и LibraryGraphUiTest: три Swing-сценария без Robot, без пропусков и ошибок. Полные XML-отчёты опубликованы отдельным архивом verification в релизе. Headless-прогон пропускает интерфейсные Swing/Robot-сценарии; такой пропуск не подтверждает их работоспособность.

Нативный EXE запущен со встроенной Java: окно Readerka 1.0.0 и отдельная тестовая SQLite-библиотека созданы, startup.log отсутствует, приложение корректно закрыто. Личная библиотека в проверке не использовалась.

Ограничения выпуска: сертификат подписи Windows отсутствует. Реальный аккаунт Dropbox и совместимость с конкретным Android-устройством не проверялись. ZIP библиотеки версии 5 не поддерживается прежними Android-версиями. Установка и обновление на другом физическом ПК требуют отдельной проверки.





Для работы DjVu на ПК без установленного Visual C++ добавлены подписанные Microsoft x86 msvcp140.dll и vcruntime140.dll версии 14.23.27820.0. Они извлекаются рядом с декодером во временный каталог; системные файлы не меняются. MSI прошёл проверку WiX с предупреждениями ICE69 о ссылках ярлыков внутри одной feature. Тестовая установка, запуск и удаление завершились с кодом 0; отдельная библиотека сохранилась.
